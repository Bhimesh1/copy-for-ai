# Windows Integration

Copy for AI is Windows-first.

## Planned Windows features

- System tray app
- Drag-and-drop file conversion
- Right-click file menu
- Global hotkey
- Clipboard copy
- Toast notifications

## Right-click menu

The target user experience is:

```text
Right-click file → Copy for AI
```

The selected file should be converted into AI-ready Markdown or text and copied directly to the clipboard.

## Hotkey

The target hotkey experience is:

``Select file → press hotkey → copied for AI``

The exact hotkey will be configurable.

## Clipboard behavior

The default behavior should be:

``Convert → copy to clipboard → show toast``

No file should be saved by default.
