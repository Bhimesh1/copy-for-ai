# Settings

Copy for AI should be simple by default and configurable for power users.

## Output format

Planned options:

- Markdown
- Plain text
- Prompt-wrapped Markdown

## Output style

Planned options:

- Clean
- Compact
- Detailed
- Raw OCR

## Metadata

Users should be able to choose whether to include:

- File name
- Page numbers
- Token estimate
- OCR warning
- Extraction timestamp

The full file path should not be included by default.

## OCR

Planned OCR modes:

- Auto
- Always
- Never

## Clipboard

Planned clipboard modes:

- Copy immediately
- Preview before copying

The default should be copy immediately.

## Privacy

The default processing mode should be local-only.

Cloud processing should never be enabled without explicit user consent.
