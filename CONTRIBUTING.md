# Contributing to Copy for AI

Thanks for your interest in contributing.

Copy for AI is an early-stage open-source project focused on making files, images, and documents easy to paste into AI tools.

## Ways to contribute

You can help with:

- Windows integration
- PDF extraction
- OCR
- Clipboard behavior
- Markdown formatting
- Token estimation
- UI/UX
- Documentation
- Testing with real files

## Development workflow

All changes should go through a pull request.

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Run checks locally.
5. Open a pull request into `main`.
6. Wait for CI and review.
7. Address review comments.
8. Merge after approval.

## Branch naming

Use clear branch names:

```text
feature/converter-cli
feature/clipboard-copy
feature/settings-page
fix/pdf-error-handling
docs/update-roadmap
ci/add-github-actions
```

## Commit style

Use simple conventional commits:

```
chore: initialize project foundation
docs: add contribution guide
feat: add clipboard copy command
fix: handle missing file path
test: add converter tests
ci: add pull request checks
```

## Pull requests

Each pull request should explain:

* What changed
* Why it changed
* How it was tested
* Screenshots, if UI changed
* Related issue, if any


## Good first issues

Issues labeled `good first issue` are suitable for new contributors.

Issues labeled `help wanted` are open for community help.
