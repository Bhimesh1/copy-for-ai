# Security Policy

## Supported versions

Copy for AI is currently in early development. Security support will apply to the latest released version once public releases begin.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Instead, contact the maintainer privately.

Maintainer:

- Bhimesh Patil
- GitHub: @bhimeshpatil1

## Security principles

Copy for AI aims to be:

- Local-first by default
- Transparent about external services
- Careful with file paths and metadata
- Careful with clipboard content
- Explicit before enabling any cloud-based processing

## Sensitive data

This app may process files that contain private or sensitive information.

The project should avoid collecting, storing, or transmitting file contents unless the user explicitly enables a feature that requires it.
