# Code of Conduct

## Our pledge

We want Copy for AI to be a welcoming and respectful open-source project.

Everyone participating in this project is expected to be respectful, constructive, and collaborative.

## Expected behavior

- Be respectful and inclusive.
- Give constructive feedback.
- Assume good intent.
- Help others learn.
- Keep discussions focused on the project.

## Unacceptable behavior

- Harassment or discrimination.
- Personal attacks.
- Trolling or insulting comments.
- Publishing private information without permission.
- Repeatedly derailing discussions.

## Enforcement

Project maintainers may remove comments, close issues, reject contributions, or block participants who violate this code of conduct.

## Reporting

To report a concern, contact the maintainer through the repository owner profile or security contact listed in [`SECURITY.md`](SECURITY.md).
